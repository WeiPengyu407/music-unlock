# 给亲戚的说明书（帮忙编译打包，全程只需要会复制粘贴）

你好！帮忙给一个开源软件打个安装包。全程大约 20-40 分钟（大部分是下载和编译的等待时间），
不需要懂编程，遇到红色报错就截图发回来。

## 第 0 步：拿到源码（二选一）

- A：对方发给你一个 `music-unlock-src.zip`，解压到桌面或任意位置
- B：自己会 git 的话：`git clone https://github.com/WeiPengyu407/music-unlock`

## Windows 电脑

1. 确认有 winget（Win10 1809+ / Win11 都有，打开 PowerShell 输 `winget --version` 有版本号就行）
2. 打开 PowerShell，`cd` 到解压出来的源码目录，例如：
   `cd ~\Desktop\music-unlock`
3. 先执行一次（允许运行脚本）：
   `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`
4. 跑构建：
   `.\packaging\build-windows.ps1`
5. 中途如果弹窗让装 Git/Python/Go/Rust，点同意即可；脚本会自动装好继续
6. 看到绿色"完成！"后，源码目录里会生成 **音乐解锁-windows-x86_64-portable.zip**，发回去即可

## Mac 电脑（M 系列芯片）

1. 先装 Homebrew（如果没有）：打开"终端"，粘贴 https://brew.sh 首页那行命令，回车，按提示输开机密码
2. 终端里 `cd` 到解压出来的源码目录，例如：
   `cd ~/Desktop/music-unlock`
3. 跑构建：
   `chmod +x packaging/build-macos.sh && ./packaging/build-macos.sh`
4. 中途要输密码就输，要等就等
5. 看到"完成！"后，源码目录里会生成 **音乐解锁-macos-arm64.dmg**，发回去即可

## 注意事项

- 中途网络报错（timeout/reset）就重跑一遍脚本，它是幂等的，会接着干
- 实在过不去的坎：截图报错发给对方
- 产物文件较大，微信发不了就用网盘/QQ 文件传输
